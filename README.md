# Portfolio starter

Open `index.html` directly in a browser. The site uses only HTML, CSS, and vanilla JavaScript.

## Personalize it

- Replace `Alex Morgan`, the bio copy, and `hello@alexmorgan.dev` in `index.html`.
- Update the GitHub and LinkedIn URLs near the bottom of `index.html`.
- When projects are ready, duplicate a `.project-card` in the `#work` section and replace its title, description, tags, and visual.
- Adjust the colors and typefaces at the top of `style.css` through the `:root` variables.

The scroll reveals, reading-progress bar, mobile navigation, cursor glow, reduced-motion fallback, and ambient card animations are all handled in `script.js` and `style.css`.
